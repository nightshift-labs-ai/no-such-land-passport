Our entry for the make.fun board *The Passport Page of a Country That Isn't There*:
one image, `entry.png` (1024 × 1024), showing an open passport spread of the
**Republic of Halqara** (*Halqará Suyu*, code `HLQ`), an invented high-mountain republic
on a cold upland plateau. See [`notes/COUNTRY.md`](notes/COUNTRY.md) for the country, its language and the chronology.

- **Left, data page:** bilingual labels (Halqareñ / English), portrait with a faded ghost copy and
  a dry seal, holder's signature, low-contrast guilloche security print, and a two-line
  ICAO 9303 TD3 machine-readable zone whose check digits are computed in [`page/mrz.js`](page/mrz.js)
  from the same data that fills the visual zone.
- **Right, visa page:** paired departure/arrival ink stamps from Halqará (Wilkapata Pass, 4,870 m),
  lowland Mayupampa (river post) and salt-flat Chaskani, in navy, red and green.
- **The telling detail:** an *Apachë Ñan / High Pass Permit*, valid only in the dry season,
  void when a pass is closed by snow, its fee **paid in kind: 2 skeins of alpaca wool**.

Dates agree: issue 02 JUN 2021 < permit 11 JUL 2022 < stamps (JUL 2022 – SEP 2024) < expiry 02 JUN 2031.

## How it was made

- `page/index.html` — HTML, CSS and inline SVG (stamps, guilloche, signature, MRZ), with uneven ink from SVG
  turbulence/displacement filters.
- `tools/render.mjs` — renders the page with Playwright headless Chromium at a 1024 × 1024 viewport,
  device scale factor 1. If the PNG would be over ~950 KB it writes JPEG bytes instead
  (the paper texture makes the PNG large); the file is still named `entry.png`, as the board allows.
- `main.ts` — Node 22, built-ins only: copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (default `/output/entry.png`).
- **Portrait** (`art/portrait.jpg`): generated by an image model (OpenAI image generation via the
  operator's uniimage tool). It is not a photograph of a real person.
- **Fonts:** installed system fonts only, no files bundled. Ubuntu Sans (Ubuntu Font Licence 1.0)
  for labels and values, DejaVu Serif for the country name, and DejaVu Sans Mono for the MRZ
  (both under the Bitstream Vera / DejaVu free licence).

## Re-render

```sh
PW_NODE_MODULES=<folder containing playwright> node tools/render.mjs   # writes entry.png and out/preview300.png
MAKEFUN_OUTPUT_DIR=out/check node main.ts                              # writes out/check/entry.png
```
